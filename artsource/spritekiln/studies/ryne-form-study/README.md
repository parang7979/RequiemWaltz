# 리네 · SpriteKiln 캐릭터 스터디

사용자가 제공한 리네 원화와 동작 시트를 보고 만든 독립 제작본이다. 기본형의 높은 은빛 포니테일과 붉은 재킷은 변신 도중 풀어지는 머리, 진주색 다리 장갑, 두 갈래의 장밋빛 옷자락으로 바뀐다. 오른쪽과 왼쪽 모습은 같은 입체 모델로 각각 렌더했다.

## 클립

| 아틀라스 | 동작 | 방향당 프레임 |
| --- | --- | --- |
| 기본형 | 대기, 달리기, 점프, 에너지 참격 | 8, 12, 16, 19 |
| 기본형 | 달리기 시작, 감속 | 7, 9 |
| 기본형 | 손 흔들기, 수정 줍기 | 17, 19 |
| 변신형 | 변신, 비행 진입, 호버 이동, 공중 180도 전환 | 28, 9, 8, 16 |

대기에서 출발할 때는 `run_start → run`, 한 주기가 끝나고 멈출 때는 `run_stop → idle`로 연결한다. 변신 직후 나아갈 때는 `transform → launch → hover`로 연결한다. 달리기 비교 GIF는 두 버전을 각각의 프레임 시간과 지면 속도로 재생한다. 수정한 달리기의 지면 속도는 96픽셀 셀에서 초당 127픽셀, 48픽셀 셀에서 초당 63.5픽셀이다. SpriteKiln이 접지로 판정한 구간에서 발 속도의 최대·최소 차이를 평균 속도로 나눈 값은 96픽셀 셀 기준 0.96에서 0.05로 줄었다.

방향 전환의 `e`는 오른쪽을 보며 시작해서 왼쪽을 보며 끝난다. 직후에는 `hover/w`를 재생한다. 반대 방향은 `air_turn/w`에서 `hover/e`로 이어진다.

## 스프라이트 파일

[96×96 셀](atlases)과 [48×48 셀](atlases/48)은 각각 해당 픽셀 밀도로 렌더했다. 셀에는 점프, 참격, 광휘를 담을 여백이 있다. 각 크기에 기본형과 변신형의 투명 컬러 PNG, 노멀 PNG, 발광 PNG, 재생용 JSON이 있다. 각 JSON에 프레임 사각형, 밀리초 단위의 재생 시간, 루프 여부, 지면 피벗, 소켓, 이벤트가 들어 있다. `*_qa.json`은 합성 전 SpriteKiln의 검사 결과다. 빌드 마지막에는 합성된 모든 프레임의 잘림과 투명 여부도 검사한다.

## 다시 렌더하기

저장소 루트에서 SpriteKiln 0.4.0 공유 체크아웃의 가상 환경으로 실행한다. 사용 중인 리비전은 [로컬 제작 설정](spritekiln.toml)에 기록했다.

```powershell
$kilnRoot = if ($env:SPRITEKILN_ROOT) { $env:SPRITEKILN_ROOT } else { '..\spritekiln' }
& "$kilnRoot\.venv\Scripts\python.exe" artsource/spritekiln/studies/ryne-form-study/build.py
```

[기본 모델](base.yaml)은 SpriteKiln의 CC0 측면 인체 및 머리·검 키트에 리네의 얼굴, 머리카락, 재킷, 스트랩, 부츠를 더했다. [기본 동작](motion.yaml)과 [변신 모델·동작](awakened.yaml)이 같은 골격을 쓴다. 검의 궤적과 수정은 SpriteKiln 기하로 렌더했다. 변신 섬광, 입자, 공중 잔광은 [픽셀 합성 코드](transform_fx.py)에서 컬러·노멀·발광에 맞춰 처리한다.

빌드는 이 폴더에 결과를 쓰고, 중간 산출물은 `out/`에 둔다. 비교표 왼쪽 열만 프로젝트의 첨부 시트 두 장에서 잘라 온다. 모델과 아틀라스는 첨부 이미지 없이 다시 렌더할 수 있다.
